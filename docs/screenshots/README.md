# CloudScope — Screenshots

Images used by the README and documentation.

| File | Purpose |
|------|---------|
| `banner.png` | Repository banner (1400×463) used at the top of the README |

The app screens are generated by the SPA, so screenshots go stale with every UI
change. To capture the current set:

```bash
cd src/client
npm ci
npm run preview:demo        # http://localhost:4300
```

Then capture (any of these works):

* **macOS** — `Cmd+Shift+4`, then drag over the window.
* **Windows** — `Win+Shift+S`.
* **Linux** — GNOME Screenshot or `flameshot`.
* **Scripted** — `npx playwright screenshot --viewport-size=1600,1000 http://localhost:4300/dashboard dashboard.png`

Suggested set (1600×1000, dark mode, browser chrome cropped out):

| Route | File |
|-------|------|
| `/dashboard` | `dashboard.png` |
| `/graph` | `graph.png` |
| `/resources` | `resources.png` |
| `/costs` | `costs.png` |
| `/compliance` | `compliance.png` |
| `/query` (with an answer) | `query.png` |

Keep files under ~400 KB each (PNG with a dark UI compresses well) and reference
them from the README with a plain `<img>` tag.
